# File Naming and Formatting Template

## Naming Convention
Use this pattern:
`{client_or_project}_{task_id}_{document_title}_{yyyymmdd}_{version}.{ext}`

Examples:
- `northstar_MON-20261114-02_policy-manual_20261115_v1.docx`
- `northstar_MON-20261114-02_table-pack_20261115_v1.csv`
- `northstar_MON-20261114-02_table-pack_20261115_v1.xlsx`

## Word Formatting Standard
- Heading 1: major section titles
- Heading 2: subsection titles
- Body text: consistent paragraph spacing
- Page numbers: footer, right aligned (or client rule)
- Tables: editable Word tables with header row
- Do not embed table screenshots when editable text is required

## Table Formatting Standard
- Keep one row per logical record
- Keep one column per field
- Keep original units in header names
- Preserve source order unless client asks for sorting

## Unreadable Text Policy
- Never guess unreadable text
- Mark as: `[UNREADABLE: page X, line Y]`
- If a whole table cell is unreadable, mark the cell value as `[UNREADABLE]`
